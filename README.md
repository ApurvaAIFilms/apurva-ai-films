# Apurva AI Films — starter project

This is an early cloud-backend starter, not a complete movie-generation system.

## Features
- Mobile-friendly web page
- Reads basic public YouTube metadata through oEmbed (does not download YouTube videos or extract their frames)
- Extracts sample frames from a video file uploaded by the user
- Optional text analysis through the OpenAI API

## Deploy
1. Upload these project files to a GitHub repository.
2. Connect the repository to a Python web host such as Render.
3. Add `OPENAI_API_KEY` in the host's private environment settings only if you want AI text analysis.
4. API usage is billed separately from a ChatGPT subscription.

Do not upload secrets or API keys to GitHub. Only upload videos you own or are authorised to use.
